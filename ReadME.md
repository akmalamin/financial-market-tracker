# 📈 NovaTrack: Real-Time Financial Market Portal

An interactive financial market intelligence dashboard built with Python, Streamlit, and Plotly. Powered by the institutional-grade Yahoo Finance API (`yfinance`), this application performs real-time market polling, traces advanced Candlestick (OHLC) formations, and renders overlays of critical Technical Indicators (SMA & EMA) on-the-fly.
